# 🚀 CollabSpace

### AI-Powered College Project & Team Finder Platform

CollabSpace is a MERN-stack web application that helps students discover projects, find teammates, collaborate in real-time, and receive AI-powered project recommendations based on their skills.

---

## 📌 Features

### Authentication & User Management

* User Registration
* User Login
* JWT Authentication
* Password Hashing using bcrypt

### Project Management

* Create Projects
* View Projects
* Update Projects
* Delete Projects
* Project Leader Management

### Team Formation

* Send Join Requests
* Approve Join Requests
* Reject Join Requests
* Automatic Team Member Addition

### Notifications

* Join Request Approval Notifications
* Join Request Rejection Notifications
* Mark Notifications as Read

### Real-Time Communication

* Team Chat using Socket.io
* Real-Time Messaging

### AI Features

* AI-Powered Project Recommendation Engine
* Skill-Based Project Matching
* Gemini AI Integration
